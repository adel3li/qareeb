# Icons

The Lucide icons قريب uses, by name, with what each means in the interface.

Use `lucide-react` (ISC licence) at stroke 1.75, round caps and joins, 20px in buttons and cards, 22px in bars, coloured by `currentColor`. A filled icon means "on" (the favourite heart). In RTL, «رجوع» is `chevron-right` and «فتح / التالي» is `chevron-left`. Every icon-only control has an Arabic `aria-label`. Add an icon to this set only when no word would do, and never use emoji.
