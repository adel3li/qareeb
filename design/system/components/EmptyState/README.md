# EmptyState

What a section shows before the user has put anything in it: the small door, one reassuring sentence, one explanation, and the action that fills it.

**Use** in الدفتر (ما وجدته, دعواتي), المكتبة before the first dua is lived, and search with no results. Centred, `space-8` around: the door (92×118, 1.5px `accent` arch with the `glow` inside, or the `mark-on-light` / `mark-on-dark` asset), the line in `subtitle`, the explanation in `body-sm`, `text-body`, then the primary Button.

**Copy:** reassure and invite; never scold. «اكتب ما تحتاجه. لن يراه أحد غيرك.» For a calendar day without a dua: «لم تعش دعاءً في هذا اليوم. لا بأس، فاليوم التالي ينتظرك.»

**The consumer provides** the sentence, the explanation and the action. **Don't** use pictures other than the door, or show an empty state while data is still loading.
