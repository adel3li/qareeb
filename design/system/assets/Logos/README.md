The logo of قريب, generated by `design/tools/build-brand.py`. `-on-light` files are for `page` and `surface` in the Stone theme (word `#1c1a17` = `text`, door `#7a6850` = `accent`, light `#0c6f68` = `cta`); `-on-dark` files for the Basalt theme (word `#f2eee6`, door `#c4b294`, light `#4cc7ba`). Lockup = word and door; wordmark = the word alone (top bar); mark = the door alone (empty states, closing screen). The repository also keeps `currentColor` versions for inline SVG. Rules in the section Logo and app icon.
