# Logo and app icon

**The word walks into the open door.** The base of the final ب in «قريب» runs on and becomes the threshold of a door, with turquoise light inside. The door is the tallest part of the logo and is drawn in `accent`, lighter than the letters, so it reads as a symbol and never as a fifth letter.

The wordmark is Reem Kufi Bold (OFL) shaped by HarfBuzz and converted to outlines: no font loads to show it. Every file is generated by `design/tools/build-brand.py` and rasterised by `design/tools/render-icons.mjs`.

## Which file

| file (Logos) | use |
|---|---|
| `lockup-on-light`, `lockup-on-dark` | the full logo: onboarding, the landing page, share images, the link preview |
| `wordmark-on-light`, `wordmark-on-dark` | the word alone: the app's top bar |
| `mark-on-light`, `mark-on-dark` | the door alone: empty states, the closing screen |

The repository also has `wordmark.svg`, `lockup.svg` and `mark.svg` in `currentColor`, for inline use in the app where the colour follows `text`.

## Rules

- Colours: the word in `text`, the door in `accent`, the light in `cta` (`glow` on screens). One-colour version where colour is not possible.
- Clear space: at least the door's width on every side.
- Minimum size: the lockup 24px tall, the wordmark 16px. Below 32px use the favicon.
- The door always ends the word, on its left. Never place it before the word, never separate them in the lockup.
- Never stretch, rotate, outline, shadow or recolour it; never set it on a photo or a busy ground; never animate the letters.

## App icon and splash

| file (App icons) | use |
|---|---|
| `icon.svg` · `icon-1024`, `icon-512`, `icon-192` | the icon: basalt, the door in stone, light spilling over the threshold. The web manifest's `any` icons (transparent corners) |
| `icon-maskable.svg` · `icon-maskable-512`, `-192` | the manifest's `maskable` icons: full bleed, the door inside the 80% safe circle |
| `apple-touch-icon` (180) | iOS home screen: full-bleed square, iOS rounds it |
| `favicon.svg`, `favicon-32` | browser tab: heavier line, no spill |

| file (Splash and social) | use |
|---|---|
| `splash-light`, `splash-dark` (1179×2556) | iOS startup images, one per colour scheme (`media="(prefers-color-scheme: dark)"`). Other device sizes are rendered from the SVGs at build time |
| `og-image-1200x630` | the link preview of the landing page and of shared dua links |

The manifest's `background_color` and `theme_color` are `page` in the light theme; `theme-color` meta tags carry both themes' `page`.
